# JAVASCRIPT

Overall Description:

The experiment focuses on two primary JavaScript concepts:  


Document Object Model (DOM): A Document object represents the HTML document displayed in a window. It contains properties that allow you to access and modify the HTML content. Elements can be found and manipulated using methods like getElementById, getElementsByTagName, getElementsByClassName, and querySelectorAll. 


JavaScript Events: These handle the interaction between JavaScript and HTML when a user or the browser manipulates the page. Event handlers are attached to elements to trigger actions during specific events, such as a mouse click (Onclick), window load (Onload), or key press (Onkeydown).
